6.
  IP-адрес — это уникальный адрес, который используется для идентификации устройства в сети и для маршрутизации данных между устройствами.
7.
  Маршруты необходимы для определения путей, по которым данные передаются от одного устройства к другому в сети. Они помогают направлять пакеты данных через различные сети и устройства.
8.
  ARP — это протокол, который используется для сопоставления IP-адресов с MAC-адресами в локальной сети, позволяя устройствам находить друг друга.
9.
  DHCP  — это сетевой протокол, который автоматически назначает IP-адреса и другие параметры конфигурации сетевым устройствам в пределах сети.
10.
  DNS — это система, которая переводит доменные имена (например, www.example.com) в IP-адреса, позволяя пользователям обращаться к ресурсам в интернете по понятным именам.
11.
  Один из протоколов синхронизации времени — NTP
12.
  Широковещательный запрос — это сообщение, отправляемое всем устройствам в сети для получения информации или выполнения определенной задачи. Он используется для обнаружения устройств или сервисов в локальной сети.
13.
  Широковещательный адрес определяется как последний адрес в подсети и обычно имеет все единицы в двоичном представлении последнего октета (например, 192.168.1.255 для подсети 192.168.1.0/24).
14.
  Дополнительные параметры, которые можно настроить на сетевой карте, включают:
    MTU 
    MAC-адрес
    Статус интерфейса (включен/выключен)
    Протоколы маршрутизации
15. 
  Маска подсети — это число, которое определяет, какая часть IP-адреса относится к сети, а какая — к устройству в этой сети. Она необходима для правильного маршрутизирования трафика между сетями и позволяет разделять адресное пространство на более мелкие подсети.
